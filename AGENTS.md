# TravelAgency repository instructions

At the start of each new session, read [Project context](docs/project-context.md) before planning or implementing work. For frontend changes, read [Frontend standards](docs/frontend-standards.md) and check the relevant items in the [WEB1 requirements checklist](docs/course-requirements.md).

- Build the main site with HTML, CSS, and JavaScript. Keep the required React recreation in its own frontend project.
- Update the project context in the same PR when the team agrees to a change in scope, page map, visitor flow, or recommendation behavior.
- Work on a task branch linked to GitHub Projects. Changes to `main` go through a PR reviewed and approved by the project lead.
- Verify affected pages and interactions using the frontend standards. State which checks you ran.
