# WEB1 course requirements

Based on the professor's *Kerkesat_Projektit_2026.pdf*, pages 3–6. The examples below show where the team plans to demonstrate the requirements. Mark items complete once verified.

## Main site

- [ ] Build a homepage and at least four functional pages using HTML, CSS, and JavaScript.
- [ ] Use semantic landmarks, logical headings, forms, tables, lists, links, and images. Use the Trip Finder questionnaire and the Compare page to demonstrate forms and tables.
- [ ] Include page titles, meta descriptions, image alt text, form labels, and keyboard navigation.
- [ ] Demonstrate backgrounds, colors, images, gradients, typography, and the box model. Use Grid and Flexbox, pseudo-classes, transitions, transforms, and keyframe animations.
- [ ] Make the site usable on mobile, tablet, and desktop, with visible hover and focus states.
- [ ] Demonstrate form validation, DOM updates, arrays, functions, objects, and event handling. Show clear success and error feedback.
- [ ] Demonstrate `map`, `filter`, `reduce`, callbacks, `setTimeout`, and date and string handling.
- [ ] Use at least one JavaScript library for a main-site interaction. A jQuery disclosure for recommendation details is one option.
- [ ] Test in at least two browsers and record the results.

## Separate React exercise

- [ ] Recreate one main-site page with React and a modern UI library. Demonstrate components, props, state, layout, typography, and interactive controls.
- [ ] Submit and present the React exercise as a separate part of the assignment.

## Team workflow and submission

- [ ] Assign a project lead to coordinate tasks, review PRs, and approve merges to `main`.
- [ ] Track tasks in GitHub Projects through **To Do → In Progress → Review → Done**. Link each task to its PR.
- [ ] Give the required mentors read access. Confirm the roster with the teaching team because the PDF calls for three mentors and lists two names.
- [ ] Submit project documentation, the GitHub repository and board links, and the PR history by the course deadline.
- [ ] Involve every teammate in the presentation. Show the site's purpose, main-site and React functionality, GitHub workflow, and challenges and solutions.
